- `src/homeprototype/HomepageWorld.tsx` — deleted. This was the rejected procedural homepage scene with repeated architectural frames, room-like staging and unrelated service objects.

## Current homepage 3D

- `src/homeprototype/KnowledgeBridgeWorld.tsx` — the sole homepage WebGL scene.
- It renders the selected concept: several authored information streams converge into one directed knowledge-to-impact field.
- STEM uses an interactive SVG experiment, and AR/VR uses CSS perspective, because those techniques communicate their section ideas more precisely.
